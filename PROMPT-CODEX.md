Trabajá sobre esta landing existente para mi startup de desarrollo de software para pequeños y medianos negocios.

El proyecto usa HTML, CSS y JavaScript sin framework. Conservá esta arquitectura y la configuración para Vercel. No agregues Angular, backend, base de datos ni dependencias sin necesidad.

Leé index.html, styles.css y script.js. Conservá el diseño responsive y la navegación accesible. Mejorá la legibilidad del código sin cambiar la apariencia. Mantené el contenido en español argentino y nombres nuevos de funciones y variables en español camelCase.

Antes de completar la marca, pedime nombre, email y WhatsApp. No inventes datos, clientes, estadísticas ni testimonios. Actualmente el formulario prepara una consulta para copiar y no envía mensajes: conservá esa aclaración hasta configurar un canal real. Si agregamos WhatsApp, el visitante debe confirmar el envío en WhatsApp.

Verificá enlaces, pestañas de ejemplos, formulario, vista móvil y escritorio. Explicame cómo verlo localmente y qué archivos cambiaste. No publiques ni crees repositorios sin que te lo pida.
